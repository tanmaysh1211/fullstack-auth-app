# Full Stack Authentication App

Tech Stack:
- React + Vite
- Zustand
- Node.js + Express
- MongoDB
- JWT Authentication
- Mailtrap (dev email)

## Features
- Signup with email verification
- Login / Logout
- Forgot password (dev mode)
- Reset password with token
- Protected routes

## Project Structure
/backend  → Express API  
/frontend → React app
